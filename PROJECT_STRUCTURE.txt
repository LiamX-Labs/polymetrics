File Descriptions:
------------------

scripts/polymarket_api_fetcher.py
  - Fetches official data from Polymarket's public API
  - Exports closed positions and trades to CSV
  - Shows summary statistics
  - NO API KEY NEEDED

scripts/wallet_analyzer.py
  - Analyzes pUSD token transfers on Polygon
  - Separates deposits/withdrawals from trading
  - Uses DEFAULT API KEY (included)
  - Interactive or command-line mode

scripts/position_analyzer.py
  - Reconstructs positions from ERC-1155 tokens
  - Tracks BUY→SELL→REDEEM lifecycle
  - Uses DEFAULT API KEY (included)
  - Exports position history to CSV

scripts/generate_performance_report.py
  - Creates professional 11-page PDF report
  - 6 performance visualizations
  - Complete trade history
  - Auto-detects latest CSV files

scripts/performance_analysis.ipynb
  - Interactive Jupyter notebook
  - Customizable analysis
  - Live data exploration

Usage Examples:
---------------

# Interactive mode (recommended)
cd scripts
python3 polymarket_api_fetcher.py
  → Prompts for wallet address
  → Uses public API (no key needed)
  → Exports to ../data/

# Command-line mode
python3 polymarket_api_fetcher.py 0xWALLET_ADDRESS

# Wallet analysis (with default API key)
python3 wallet_analyzer.py
python3 wallet_analyzer.py 0xWALLET_ADDRESS

# Position reconstruction (with default API key)
python3 position_analyzer.py
python3 position_analyzer.py 0xWALLET_ADDRESS

# Generate PDF report
python3 generate_performance_report.py
  → Auto-finds latest CSV files in ../data/
  → Saves PDF to current directory
